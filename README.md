# Active Directory IAM Platform

An enterprise-style Identity and Access Management (IAM) platform
for managing Microsoft Active Directory users, accounts, groups,
permissions, and access workflows.

## Features

- Active Directory user search and profile management
- Enable / disable user accounts (AD DC integration )
- Password reset (AD DC integration )
- Account unlock (AD DC integration )
- Active Directory group membership retrieval
- LDAP / LDAPS integration (screenshot provided)
- JWT authentication 
- Role-based authorization 
- Permission management
- Access request workflows (screenshot provided)
- Audit logging(screenshot provided)
- Blazor Server administration interface
